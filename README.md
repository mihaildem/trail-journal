# Тропа и контекст

Небольшой статический сайт на Astro. Отчёты хранятся в Markdown в `src/content/`; главная и каталог маршрутов собираются из этих файлов.

## Требования

- Node.js 20.3.0 или новее
- npm

## Запуск локально

```sh
npm install
npm run dev
```

Откройте адрес, который покажет Astro в терминале.

## Добавить отчёт

1. Скопируйте `src/content/svanetia.md` и переименуйте копию, например в `src/content/arkhyz.md`.
2. Заполните поля YAML вверху файла. Схема полей описана в `src/content.config.ts`.
3. Пишите текст ниже разделителя `---` в Markdown: заголовки, списки, цитаты, таблицы и изображения.
4. Положите изображения в `public/images/` и укажите путь от корня сайта, например `/images/arkhyz-cover.jpg`.
5. Проверьте сайт через `npm run dev`, затем выполните `npm run build`.

## Сборка

```sh
npm run build
npm run preview
```

Готовый статический сайт появится в `dist/`. Его можно разместить на хостинге, который раздаёт статические файлы.
